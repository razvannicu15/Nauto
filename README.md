# Nauto

Diagnostic pentru Android Auto wireless (AAWireless). Fără reclame, fără cont — totul rămâne pe telefon. *by norAz*

## Ce face
- Rulează în fundal și înregistrează fiecare conectare: Bluetooth adaptor, Wi-Fi, pornirea Android Auto, baterie/Doze/ecran, alte dispozitive Bluetooth.
- Împarte jurnalul pe drumuri și marchează fiecare: OK, lentă, cu reîncercări, întreruptă, eșuată.
- După câteva drumuri spune cauza probabilă (mașină/USB, Wi-Fi telefon, Wi-Fi acasă, alt Bluetooth, baterie, canal Wi-Fi…) și ce să faci.
- Buton „Am avut o problemă” în notificare.
- Export raport complet în `Download/Nauto`.
- Mod avansat (opțional): jurnalele de sistem Android Auto / Wi-Fi / Bluetooth, activat din `Nauto.bat` → [6].

## Instalare
Rulează `Nauto.bat` → [1] descarcă APK-ul, [2] instalează pe telefon prin cablu.
APK-ul se construiește automat pe GitHub la fiecare commit (Releases → latest).
